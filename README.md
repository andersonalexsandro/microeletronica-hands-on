# AES Top-Level System

Projeto integrador da trilha **RTL Design** da Residência em Microeletrônica CI-Expert: um sistema de topo com datapath AES, configurado e controlado por uma interface SPI, que recebe e devolve dados por uma interface de dados com memória e conta com blocos de reset e de geração de clock.
